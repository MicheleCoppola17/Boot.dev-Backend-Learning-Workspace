The learning goals of this project are as follows:

- Get an introduction to multi-directory Python projects.
- Understand how the AI tools that you'll almost certainly use on the job actually work under the hood.
- Practice your Python and functional programming skills.

The goal is not to build an LLM from scratch, but instead to use a pre-trained LLM to build an agent from scratch.
